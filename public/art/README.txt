Optional art slots (made in Gemini Flow by the owner). Drop a file here and the invitation cards use it
automatically; if a file is missing the cards show a clean CSS/SVG fallback.

Names (category = wedding | birthday | funeral | other):
  corner-<category>.webp   top-left corner ornament, transparent, 600x600. Mirrored by CSS for the other corners.
  divider-<category>.webp  thin horizontal divider, transparent, 900x120.
  seal-<category>.webp     wax seal without letters, transparent, 400x400. The monogram is added by CSS.
Full specs and prompts: docs/design/flow-briefs.md
